# Ceiba Book — design replica

Static visual replica of the Ceiba Intercontinental `/book` page and KIU booking widget (including the plane loading spinner from `booking.ceibaintercontinentalairlines.com`).

## Run locally

```bash
cd web
python3 -m http.server 8765
```

Open `http://127.0.0.1:8765/`.

## Notes

- Search / newsletter / login are **demo-only** (no live booking API, no credential capture).
- Assets and styles mirror the public marketing site for design reference.
